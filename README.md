---

## Sobre o Material

O guia foi desenhado para servir tanto como material interativo durante a oficina prática quanto como consulta rápida no dia a dia acadêmico e profissional. 

Ele aborda a anatomia estrutural de comandos eficazes para Modelos de Linguagem Grande (LLMs):

1. **Papel / Persona:** Definição da autoridade/tom da IA.
2. **Contexto:** Cenário específico e realidade de aplicação (com foco no público e economia local).
3. **Tarefa Clara:** Ação executável objetiva.
4. **Formato de Saída:** Estrutura final (tabelas, listas, relatórios).
5. **Restrições:** Limites de escopo, orçamento e extensão.
6. **Exemplos (Few-Shot):** Modelos de padrão esperado para orientar a resposta.

## Tecnologias Utilizadas

- **HTML5 & CSS3 Semântico:** Layout responsivo otimizado para navegação mobile e desktop.
- **Suporte Nativo a Modo Escuro:** Adaptação automática via `prefers-color-scheme` e atributos de acessibilidade visual.
- **Folha de Estilos para Impressão:** Regras `@media print` sem quebra indevida de elementos para distribuição de folhas de exercícios.
- **GitHub Pages:** Hospedagem estática de alta disponibilidade e entrega contínua.
